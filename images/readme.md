# Lindokuhle Mchilwa - Personal Portfolio Website

## Project Description

This is a fully responsive multi-page personal portfolio website created as part of the **by Lindokuhle Mchilwa**.  
The website showcases my personal information, education background, skills, certifications, projects, hobbies, and future goals.

The website is built using **HTML5**, **CSS3**, and **JavaScript**, and includes modern interactive features such as dark mode, typing effect, digital clock, image slideshow, and form validation.

---

## Features

- Responsive design (works on mobile, tablet, and desktop)
- Dark Mode / Light Mode toggle
- Mobile hamburger navigation menu
- Typing effect on the homepage
- Live digital clock
- Image slideshow on the Hobbies page
- Show/Hide toggle sections
- Scroll-to-top button
- Contact form with JavaScript validation
- Clean and modern UI with smooth animations

## Technologies Used

- **HTML5** – Structure of the website

- **JavaScript** – Interactivity and dynamic features

- **Google Fonts** – Poppins font family

---

## How to Run the Project

1. Download or clone the project folder.
2. Open the folder in any code editor (VS Code recommended).
3. Open `index.html` in a web browser (Chrome, Edge, Firefox, etc.).
4. Navigate through the different pages using the navigation menu.

> **Note:** Make sure the `images` folder contains your profile picture and project images.
